# E4235

Compiler diagnostic name: `lexscan_target_type_unknown`.

The type of a `lexscan` target is not known when the expression is checked.
The compiler needs this type to determine whether to scan text or bytes.

## Erroneous example

```{literalinclude} /sources/error_codes/4235_error/top.mbt
:language: moonbit
```

## Suggestion

Annotate the target or the parameter that supplies it. In this example, annotate
the local function's parameter rather than relying on its later call to infer
the type.

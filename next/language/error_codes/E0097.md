# E0097

Warning name: `regex_runtime_fallback`

The regex match exceeds a compilation resource limit and uses the runtime
regex engine instead. The match is still accepted; this warning is not a
runtime matching error.

This warning is disabled by default. Enable `regex_runtime_fallback` in the
package warning configuration to receive it.

## Erroneous example

```{literalinclude} /sources/error_codes/0097_error/top.mbt
:language: moonbit
```

This pattern matches binary strings whose twenty-first character from the end
is `1`. Compiling it exceeds a resource limit; the runtime engine can still
match it. The exact limit may change between compiler versions.

## Suggestion

If the fallback is acceptable, no correctness fix is required. If performance
matters, measure the affected operation and consider simplifying the patterns
or splitting the match into smaller operations.

To choose runtime matching explicitly while preserving the pattern, call
`execute` and check whether it returns a match:

```{literalinclude} /sources/error_codes/0097_fixed/top.mbt
:language: moonbit
```

If runtime fallback is unavailable, exceeding the compilation limit produces
[E4233](./E4233.md) instead.

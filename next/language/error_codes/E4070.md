# E4070

Unknown intrinsic. This intrinsic is not known to the MoonBit compiler.

This error applies to a direct intrinsic declaration (`fn ... = "name"`),
which has no ordinary function body to fall back to. An unknown name in a
`#intrinsic("name")` attribute instead produces warning [E0094](E0094.md):
the attribute is ignored and the ordinary function body is used.

Intrinsics are not intended for usage outside of `moonbitlang/core`. They are
subject to change without notice, and we highly recommend **against** using them.

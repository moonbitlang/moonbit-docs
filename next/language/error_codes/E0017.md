# E0017

Warning name: `ambiguous_loop_argument`

This warning applies to an ambiguous reference to the initial state of the
deprecated functional-loop syntax. Use a `for` loop with explicit state
bindings instead. This makes the current state distinct from the original
value, without relying on a pattern alias.

## Suggestion

To refer to the state that changes on each iteration, use the variable bound
in the `for` header:

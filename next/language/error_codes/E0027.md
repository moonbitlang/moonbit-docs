# E0027

Warning name: `deprecated_syntax`

The compiler may emit this warning when it still accepts outdated syntax for
compatibility. Follow the diagnostic's suggested replacement and migrate the
code promptly.

Deprecated syntax is temporary and may be removed in a later compiler release.
After removal, the same source may produce a syntax error instead of this
warning. Therefore, this page does not use a checked source example tied to one
particular deprecated form; refer to the diagnostic for its exact replacement.

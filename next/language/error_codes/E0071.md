# E0071

Warning name: `core_package_not_imported`

Core package used without an explicit import.

This warning describes older compiler behavior. Current compilers require
explicit imports for core packages and report [E4037](./E4037.md) instead.

Older compilers recognized some packages under `moonbitlang/core` by their
conventional aliases and warned about implicit imports. Add the package to
`moon.pkg` instead; the following erroneous example now produces E4037.

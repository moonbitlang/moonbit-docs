# E4224

Compiler diagnostic name: `lexscan_catchall_missing`.

A `lexmatch` or `lexscan` expression has no final catch-all case.

Regex cases do not necessarily cover every possible input, including an empty
input. Add a final `_` branch to define the result when no regex case matches.

## Erroneous example

```{literalinclude} /sources/error_codes/4224_error/top.mbt
:language: moonbit
```

## Suggestion

Add a final `_` case. If a catch-all exists but is not last, see
[E4171](E4171.md).

```{literalinclude} /sources/error_codes/4224_fixed/top.mbt
:language: moonbit
```

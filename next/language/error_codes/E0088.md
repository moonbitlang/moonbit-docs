# E0088

Warning name: `guard_redundant_bang`

The condition or pattern of a `guard!` is exhaustive, so it cannot fail and the
explicitly terminating form is unnecessary.

```{literalinclude} /sources/error_codes/0088_error/top.mbt
:language: moonbit
```

## Suggestion

Replace `guard!` with `guard`.

# E4118

Cannot match type with map pattern.

This diagnostic is reported when a map pattern is used on a type without a
suitable `get` method. Map patterns on custom types with a `get` method are
deprecated; use the standard library's `Map` type instead.

```{literalinclude} /sources/error_codes/4118_error/top.mbt
:language: moonbit
```

## Suggestion

Use a `Map` for map-pattern matching, rather than adding a `get` method to a
custom type solely to support this syntax.

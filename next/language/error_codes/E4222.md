# E4222

Compiler diagnostic name: `invalid_lexscan_target`.

Invalid lexical matching target.

`lexmatch` accepts an in-memory `String` or `StringView`. Streaming `lexscan`
accepts `@lexbuf.Lexbuf` or `@lexbuf.AsyncLexbuf`. Other values, such as
numbers, cannot be matched by these expressions.

## Suggestion

Use `lexmatch` with a string-like value, or create a lexing buffer for
`lexscan`.

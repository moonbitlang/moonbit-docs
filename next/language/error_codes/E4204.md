# E4204

Compiler diagnostic name: `loop_nobreak_not_supported`.

This diagnostic applies to a `nobreak` clause on the deprecated functional-loop
syntax. Use a `for` loop with explicit state bindings instead.

## Suggestion

Use `break` with a value to return the result. A `for` loop without a condition
continues until an explicit exit, so no `nobreak` clause is needed:

# E4219

Compiler diagnostic name: `invalid_export_name`.

The `#export_name` attribute is invalid. Export names must be unique within the package. Name restrictions depend on
the backend: native requires valid C symbol identifiers, while WebAssembly
export names are UTF-8 strings and are not limited to C identifiers.

The attribute may be used only on public, non-generic function definitions
without optional arguments in a foreign-library package.

## Erroneous example

Both functions use the export name `add_one`, which must be unique:

:language: moonbit
```

## Suggestion

:language: moonbit
```

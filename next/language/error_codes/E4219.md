# E4219

Compiler diagnostic name: `invalid_export_name`.

The `#export_name` attribute is invalid. MoonBit currently requires exported
names to be unique valid C symbol identifiers for every backend. This is a known
compiler issue: the attribute applies this cross-backend restriction even
though WebAssembly export names themselves are UTF-8 strings and are not
limited to C identifiers. The attribute may be used only on public, non-generic
function definitions without optional arguments in a foreign-library package.


## Suggestion

Use a valid symbol name and declare the package as a foreign library with
`pkgtype(kind: "foreign_library")`.

# E3012

Struct pattern and map pattern cannot be mixed. The key in map pattern must be a
literal, while the key in struct pattern must be the field name.

## Erroneous example

```{literalinclude} /sources/error_codes/3012_error/top.mbt
:language: moonbit
```

## Suggestion

Use a map pattern for a standard-library `Map`:

```{literalinclude} /sources/error_codes/3012_fixed/top.mbt
:language: moonbit
```

Or use a struct pattern for a struct value:

```{literalinclude} /sources/error_codes/3012_fixed/top_1.mbt
:language: moonbit
```

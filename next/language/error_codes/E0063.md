# E0063

Warning name: `syntax_lint`

Syntax lint warning.

This warning category is used for valid code patterns that the compiler accepts
but discourages. For example, wrapping a supplied optional argument in `Some`
is unnecessary:

```{literalinclude} /sources/error_codes/0063_error/top.mbt
:language: moonbit
```

## Suggestion

Pass the value directly when supplying the optional argument:

```{literalinclude} /sources/error_codes/0063_fixed/top.mbt
:language: moonbit
```

Other syntax lint diagnostics may report different anti-patterns and provide a
suggestion specific to the code being checked.

# E4233

Compiler diagnostic name: `regex_execution_limit_exceeded`.

The regex match exceeds a compilation resource limit and cannot use the runtime
fallback. This is a compile-time error, not a timeout while matching input.

## Erroneous example

```{literalinclude} /sources/error_codes/4233_error/top.mbt
:language: moonbit
```

This streaming scan exceeds the compilation limit and cannot use runtime
fallback. It matches binary strings whose twenty-first character from the end
is `1`.

## Suggestion

Simplify the regex patterns or split the operation into smaller matches.
Preserve the intended matching order and captures when splitting a match.

Here, scan the binary digits with a simpler pattern, then check the character
position directly. This preserves the condition tested by the original pattern.

```{literalinclude} /sources/error_codes/4233_fixed/top.mbt
:language: moonbit
```

The diagnostic reports the resource limit that was exceeded. Limits may change
between compiler versions, so do not rely on a particular threshold.

When runtime fallback is available, the compiler can instead accept the match
and report [E0097](./E0097.md) if that warning is enabled.

# E0030

Warning name: `missing_package_alias`

The package alias is empty. The default package alias will be used instead.
This warning applies to the legacy `moon.pkg.json` format. Current `moon`
commands reject JSON manifests, and `moon.pkg` cannot express an explicitly
empty alias. The examples below are retained as migration references.

## Erroneous example

```json
{
  "import": [
    {
      "path": "moonbit-community/E0030/lib",
      "alias": ""
    }
  ]
}
```

## Suggestion

Use a non-empty alias for the package:

```json
{
  "import": [
    {
      "path": "moonbit-community/E0030-fixed/lib",
      "alias": "hello"
    }
  ]
}
```

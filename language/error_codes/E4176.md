# E4176

Compiler diagnostic name: `invalid_lexmatch_target`.

This diagnostic code was used for an invalid `lexmatch` target and is not
emitted by the current compiler. The current diagnostic is [E4222](https://docs.moonbitlang.com/en/latest/language/error_codes/E4222.html).

`lexmatch` works on textual views. The target expression must have a type that
can be matched by regex patterns, such as `String` or `StringView`, instead of a
numeric, boolean, or other unrelated type.

## Erroneous example

```moonbit
///|
pub fn match_number(n : Int) -> Unit {
  lexmatch n with longest {
    _ => ()
  }
}
```

The target is an `Int`, which cannot be consumed by `lexmatch`.

## Suggestion

Match a `String` or `StringView`, or convert the input before matching.

```moonbit
///|
pub fn match_text(text : String) -> Unit {
  lexmatch text with longest {
    _ => ()
  }
}
```

# E0096

Warning name: `unfenced_import`

An `.mbtx` script declares imports outside its frontmatter. This older form
is deprecated.

## Erroneous example

```moonbit
import {
  "moonbitlang/core/queue" @queue
}

///|
fn main {
  println(@queue.Queue([1, 2]).length())
}
```

## Suggestion

Move the imports into frontmatter at the beginning of the script, enclosed
by `---` lines. Package imports in `moon.pkg` do not need these delimiters.

```moonbit
---
import {
  "moonbitlang/core/queue" @queue
}
---

///|
fn main {
  println(@queue.Queue([1, 2]).length())
}
```

See [Running `.mbtx` Scripts](https://docs.moonbitlang.com/en/latest/toolchain/moon/script-mode.html) for dependencies,
aliases, and import-all syntax.

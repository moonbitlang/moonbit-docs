# E4232

Compiler diagnostic name: `regex_constant_in_pattern`.

A regex constant cannot be used as an ordinary pattern. Matching a constant
in a regular `match` is not the same as applying a regex to text or bytes.

## Erroneous example

```moonbit
///|
pub const WORD = re"[a-z]+"

///|
pub fn matches(value : Regex) -> Bool {
  match value {
    WORD => true
    _ => false
  }
}
```

## Suggestion

For text matching, use the regex with `=~`, `lexmatch`, or `lexscan`.
Do not use an ordinary constant pattern to compare regex values.

```moonbit
///|
pub const WORD = re"[a-z]+"

///|
pub fn matches(text : String) -> Bool {
  text =~ WORD
}

///|
test {
  assert_true(matches("hello"))
  assert_false(matches("123"))
}
```

For a byte regex constant, use its `execute` method to match bytes.

# E4028

This expression has a type which is not a struct.

## Erroneous Example

```moonbit
pub struct T {
  a : Int32
}

pub let a : Int32 = { a: 42 }
```

The example above tries to assign a struct of type `T` to a variable `a` of type `Int32`,
which is not possible and gives the following error on line 2:

```none
This expression has type Int32, which is a Int32 type and not a struct.
```

## Suggestion

Make sure to use the correct type instead:

```moonbit
pub struct T {
  a : Int32
}

pub let a : T = { a: 42 }
```

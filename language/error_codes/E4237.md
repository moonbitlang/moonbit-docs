# E4237

Compiler diagnostic name: `lexscan_target_impl_conditional`.

The target has a scanning trait implementation, but that implementation is not
eligible for `lexscan`. It must apply to every instance of the target type,
without bounds on its type parameters, or be a non-generic implementation for
the exact, fully known target type.

An implementation with a type parameter bound is rejected even when the target
satisfies that bound. Partially specialized implementations, such as one for
`Scanner[Array[T]]`, are also rejected.

## Erroneous example

```moonbit
///|
pub(all) struct Scanner[T] {
  input : StringView
  mut cursor : Int32
  tag : T
}

///|
impl[T : Show] @lexbuf.Scannable for Scanner[T] with fn scan_input(self) {
  self.input
}

///|
impl[T : Show] @lexbuf.Scannable for Scanner[T] with fn scan_cursor(self) {
  self.cursor
}

///|
impl[T : Show] @lexbuf.Scannable for Scanner[T] with fn set_scan_cursor(self, cursor) {
  self.cursor = cursor
}

///|
pub fn scan_word(target : Scanner[Int32]) -> Bool {
  lexscan target {
    re"^[a-z]+" => true
    _ => false
  }
}
```

## Suggestion

Remove unnecessary bounds from the implementation, as below. If the bounds are
needed, use a wrapper with an eligible implementation instead. If an exact
non-generic implementation exists, annotate the target so its type is fully
known.

```moonbit
///|
pub(all) struct Scanner[T] {
  input : StringView
  mut cursor : Int32
  tag : T
}

///|
impl[T] @lexbuf.Scannable for Scanner[T] with fn scan_input(self) {
  self.input
}

///|
impl[T] @lexbuf.Scannable for Scanner[T] with fn scan_cursor(self) {
  self.cursor
}

///|
impl[T] @lexbuf.Scannable for Scanner[T] with fn set_scan_cursor(self, cursor) {
  self.cursor = cursor
}

///|
pub fn scan_word(target : Scanner[Int32]) -> Bool {
  lexscan target {
    re"^[a-z]+" => true
    _ => false
  }
}
```

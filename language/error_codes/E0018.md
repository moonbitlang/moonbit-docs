# E0018

Warning name: `useless_loop`

This warning applies to the deprecated functional-loop syntax when it has no
`continue` statement and therefore executes only once. Use a `for` loop for
repeated execution, or `if`/`match` for a single conditional evaluation.

## Suggestion

Use explicit state bindings, a condition, and an update clause to count down:

```moonbit
///|
fn main {
  let count = 2
  for remaining = count; remaining >= 0; remaining = remaining - 1 {
    println(remaining)
  }
}
```

Output:

```none
2
1
0
```

Use `if`/`match` when no repetition is needed:

```moonbit
///|
fn main {
  let count = 2
  match count {
    _..<0 => ()
    _ => println(count)
  }
}
```

Output:

```none
2
```

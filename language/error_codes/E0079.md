# E0079

Warning name: `implicit_impl_as_method`

Methods from an `impl Trait for Type` declaration are being attached to `Type`
implicitly. This compatibility behavior is deprecated because it is not
explicit or refactoring-safe.

This diagnostic describes the former implicit-attachment compatibility behavior.
Without an explicitly attached method, current toolchains report
[E4015](https://docs.moonbitlang.com/en/latest/language/error_codes/E4015.html) instead.

## Suggestion

Use `extend Type with Trait::{method}` for methods that should support dot
syntax. If the compatibility method should remain available only for migration,
mark that `extend` declaration with `#deprecated`. Otherwise, call the
implementation as `Trait::method(value)`.

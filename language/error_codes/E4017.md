# E4017

Method of type is ambiguous, it may come from multiple traits.

## Erroneous Example

```moonbit
///|
pub(open) trait A {
  fn value(Self) -> Int32
}

///|
pub(open) trait B {
  fn value(Self) -> Int32
}

///|
pub fn[T : A + B] read(x : T) -> Int32 {
  x.value()
}
```

The example above tries to call the method `value` on a value of type `T`.
The type parameter is constrained by both `A` and `B`, which each define `value`,
giving an error like:

```none
Method value of type T is ambiguous, it may come from trait A or B
```

## Suggestion

Disambiguate the method by specifying the trait it comes from:

```moonbit
///|
pub(open) trait A {
  fn value(Self) -> Int32
}

///|
pub(open) trait B {
  fn value(Self) -> Int32
}

///|
pub fn[T : A + B] read(x : T) -> Int32 {
  A::value(x) + B::value(x)
}
```

# E0008

Warning name: `redundant_modifier`

The modifier (`pub`/`priv`) is redundant here, since this field has such
visibility by default.

## Erroneous example

```moonbit
///|
struct A {
  priv value : Int32
  //^^
}

///|
pub struct B {
  pub value : Int32
  //^
}
```

## Suggestion

Remove the visibility modifier on the field.

```moonbit
///|
struct A {
  value : Int32
}

///|
pub struct B {
  value : Int32
}
```

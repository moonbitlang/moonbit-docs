# E0098

Warning name: `cancellable_defer`

A `defer` or `errdefer` expression contains cancellable asynchronous code.
If cancellation triggers the cleanup, its asynchronous operations can be
cancelled immediately as well, preventing the cleanup from completing.

## Erroneous example

The examples use the experimental standard-library async runtime:

```moonbit
import {
  "moonbitlang/core/async",
}
options("allow-experimental-packages": true)
```

```moonbit
///|
pub async fn operation() -> Unit {
  defer @async.sleep(1)
  @async.sleep(1)
}
```

## Suggestion

Protect required asynchronous cleanup from cancellation. With
`moonbitlang/core/async`, wrap it in `@async.protect_from_cancel`:

```moonbit
///|
pub async fn operation() -> Unit {
  defer @async.protect_from_cancel(() => @async.sleep(1))
  @async.sleep(1)
}
```

Synchronous cleanup does not need this wrapper. Keep protected cleanup bounded
so that cancellation does not wait indefinitely for it to finish.

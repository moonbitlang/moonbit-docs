# E4236

Compiler diagnostic name: `lexscan_target_ambiguous`.

The target of `lexscan` supports both `@lexbuf.Scannable` and
`@lexbuf.BytesScannable`, so the compiler cannot choose text or byte scanning.
The regex cases do not resolve this ambiguity.

## Erroneous example

```moonbit
///|
pub fn[T : @lexbuf.Scannable + @lexbuf.BytesScannable] scan_word(
  target : T,
) -> Bool {
  lexscan target {
    re"^[a-z]+" => true
    _ => false
  }
}
```

## Suggestion

For a generic function, require only the scanning trait it needs. For a concrete
type that implements both traits, use a wrapper that implements just one.

```moonbit
///|
pub fn[T : @lexbuf.Scannable] scan_word(target : T) -> Bool {
  lexscan target {
    re"^[a-z]+" => true
    _ => false
  }
}
```

# E0029

Warning name: `unused_package`

This warning is emitted when a package is listed as an import but the current
package does not use that import directly. Explicit imports from
`moonbitlang/core` are checked as well.

Finding a method or trait implementation through a value's type does not by
itself make an explicit import necessary. An import used only for such indirect
lookup may therefore still be reported as unused.

## Erroneous example

```moonbit
name = "moonbit-community/E0029"
```

```none
// This package has no package-specific configuration.
```

```none
import {
  "moonbit-community/E0029/lib", // Warning: Unused package
}

pkgtype(kind: "executable")
```

```moonbit
///|
fn main {

}
```

## Suggestion

Remove the unused package. If the code needs an API from that package directly,
refer to it through the package alias instead:

```none
pkgtype(kind: "executable")
```

# E3012

Struct pattern and map pattern cannot be mixed. The key in map pattern must be a
literal, while the key in struct pattern must be the field name.

## Erroneous example

```moonbit
///|
test {
  let map : Map[String, Int32] = { "value": 42 }
  match map {
    { "value": value, value, .. } => println("Value is: \{value}") // Error: Struct pattern and map pattern cannot be mixed.
    _ => println("No value")
  }
}
```

## Suggestion

Use a map pattern for a standard-library `Map`:

```moonbit
///|
fn use_map_pattern(map : Map[String, Int32]) -> Unit {
  match map {
    { "value": value, .. } => println("Value is: \{value}")
    _ => println("No value")
  }
}

///|
test {
  let map : Map[String, Int32] = { "value": 42 }
  use_map_pattern(map)
}
```

Or use a struct pattern for a struct value:

```moonbit
///|
priv struct S {
  value : Int32
}

///|
fn use_struct_pattern(s : S) -> Unit {
  match s {
    { value, } => println("Value is: \{value}")
  }
}

///|
test {
  use_struct_pattern({ value: 42, })
}
```

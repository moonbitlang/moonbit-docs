# E0081

Warning name: `regex_match_missing_after`

A `lexmatch` pattern can leave an unmatched input suffix, but the
pattern does not bind or explicitly ignore that suffix.

Add `$` when the match must end with the input, or add `after=` to bind or
ignore the remaining suffix.

## Erroneous example

```moonbit
///|
pub fn starts_with_digits(input : String) -> Bool {
  lexmatch input {
    re"^[0-9]+" => true
    _ => false
  }
}
```

## Suggestion

Anchor the regex at the end, or make the suffix explicit with `after=suffix` or
`after=_`.

```moonbit
///|
pub fn starts_with_digits(input : String) -> Bool {
  lexmatch input {
    (re"^[0-9]+", after=_) => true
    _ => false
  }
}
```

# E0087

Warning name: `guard_inexhaustive`

A `guard` without an `else` clause may fail. When its condition is false or its
pattern does not match, it would implicitly terminate the program.

## Erroneous example

```moonbit
///|
pub fn unwrap(value : Int32?) -> Int32 {
  guard value is Some(result)
  result
}
```

## Suggestion

Add an `else` clause to handle failure, or use `guard!` when termination is
intentional.

```moonbit
///|
pub fn unwrap_or_zero(value : Int32?) -> Int32 {
  guard value is Some(result) else { 0 }
  result
}

///|
pub fn require_some(value : Int32?) -> Int32 {
  guard! value is Some(result)
  result
}
```

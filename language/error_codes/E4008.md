# E4008

FFI function cannot have type parameters.

## Erroneous Example

```moonbit
pub extern "js" fn[T] id(x : T) -> T = "(x) => x"
```

The example declares an FFI function (marked `extern`) with a type parameter,
which is not allowed.

## Suggestion

Consider using a concrete type that suits your needs:

```moonbit
///|
extern "js" fn int_id(x : Int32) -> Int32 = "(x) => x"

///|
pub fn concrete_id(x : Int32) -> Int32 {
  int_id(x)
}
```

For more complicated scenarios, consider adding an extra trait:

```moonbit
///|
pub(open) trait Ider {
  id(Self) -> Self
}

///|
impl Ider for Int32 with id(self) {
  concrete_id(self)
}

///|
pub fn trait_id(x : Int32) -> Int32 {
  Ider::id(x)
}
```

# E4037

Compiler diagnostic name: `pkg_not_imported`.

The referenced package is not imported.

The example refers to `@boolean`, but no package with that alias is imported.

## Erroneous example

```moonbit
fn main {
  println(@boolean.Bool::to_int(true))
}
```

## Suggestion

Check the package name and import the required package in `moon.pkg`.
In this example, `Bool` is a built-in type, so call its method directly
without a package alias.

```moonbit
fn main {
  println(true.to_int())
}
```

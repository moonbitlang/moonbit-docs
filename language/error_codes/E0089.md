# E0089

Warning name: `guard_redundant_else`

The condition or pattern of a `guard` is exhaustive, so its `else` clause can
never run.

## Erroneous example

```moonbit
///|
pub fn identity(value : Int) -> Int {
  guard value is result else { 0 }
  result
}
```

## Suggestion

Remove the unreachable `else` clause.

```moonbit
///|
pub fn identity(value : Int) -> Int {
  guard value is result
  result
}
```
